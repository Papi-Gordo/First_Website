# My First HTML5 Website

## Description

This project is my first attempt at building a functional website using HTML5. The purpose of this project was to familiarize myself with the basic structure of HTML documents, creating multiple web pages, and linking them together using a navigation menu.

## Features

Website includes:
- Three HTML pages
- Navigation menu
- Internal and external hyperlinks

## Technologies Used 

I built this website using **HTML** withouth any CSS or Javascript

## What I Learned

I learned how to organize HTML files and how to *link multiple pages together*

Learn more about HTML at [W3Schools] (https://www.w3schools.com/html/)
